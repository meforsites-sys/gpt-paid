# ALI MU'IZ ENGLISH 2027 — إنكليزي السادس الإعدادي

تطبيق تعليمي واحد الملف لمادة اللغة الإنكليزية — الصف السادس الإعدادي (العراق)، من إعداد الأستاذ **علي معز الشلاه**. يعمل **دون إنترنت تماماً**: كل المحتوى والخطوط مضمّنة داخل الملف.

**الإصدار المعتمد حالياً: `1.12.9` — إصدار إصلاح البحث (SEARCH_FIX).**

3. بعد التثبيت افتح التطبيق — لا يحتاج إنترنت ولا أي صلاحية.

## ما الجديد في 1.12.9

- فهرسة مرجع القواعد التفصيلي `GRAMMAR_REFERENCE_111` (26 موضوعاً) داخل البحث الذكي، فصار البحث يصل إلى شرح كل قاعدة وتمارينها.
- مرادفات صريحة: `Passive voice` ↔ المبني للمجهول، `Expectation` ↔ التوقع.
- توسيع الفهرسة لتشمل عناوين وتعليمات تمارين الوحدات.
- **ضمّ الخطوط** (Tajawal + Poppins) داخل الملف بصيغة base64 بدلاً من تحميلها من Google Fonts، فأصبح العرض صحيحاً بلا شبكة.

## النسخة على الويب

`index.html` في جذر المستودع هو التطبيق كاملاً في ملف واحد — افتحه في أي متصفح حديث. وهو **مطابق بايت-ببايت** للملف المضمّن داخل الـAPK.

## بنية المستودع

```
index.html                              التطبيق المعتمد (v1.12.9، خطوط مضمّنة)
انكليزي-السادس-الاعدادي-2027-v1.12.9.apk  حزمة أندرويد موقّعة من نفس الملف
CHANGELOG_SEARCH_FIX.md                 سجل تغييرات 1.12.9
BUILD_SEARCH_FIX_REPORT_AR.md           تقرير إصلاح البحث وحدود الاختبار
HANDOVER-انكليزي-السادس-الاعدادي.md      وثيقة تسليم المشروع
app/
  english2027/index_v1.12.9_original.html  المصدر الأصلي كما وصل (خطوط Google)
  english2027/index.html                   ناتج البناء (خطوط مضمّنة)
  android_english2027/                     مشروع أندرويد (manifest + Java + أيقونات)
  tools/make_v1129_offline.py              تضمين الخطوط وإنتاج index.html
  tools/build_apk_2027.py                  بناء APK موقّع دون Gradle
  web/                                     الواجهة الأولى وبياناتها وخطوطها
```

## إعادة البناء

```bash
py app/tools/make_v1129_offline.py          # ينتج index.html بخطوط مضمّنة
E2027_KS_PASS=... py app/tools/build_apk_2027.py   # ينتج الـAPK الموقّع
```

كلمة مرور مفتاح التوقيع تُقرأ من متغيّر البيئة `E2027_KS_PASS` فقط، ولا تُكتب في المستودع.
